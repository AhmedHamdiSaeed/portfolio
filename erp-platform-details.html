Enterprise SaaS ERP Platform

Live Demo: erpplatform-gamma.vercel.app

A modern, multi-tenant enterprise resource planning (ERP) system architected with ABP Framework and .NET 9 backend paired with a cutting-edge Angular 20 frontend SPA.

Engineered following Domain-Driven Design (DDD) principles with distinct domain, application, and infrastructure layers across core business modules (HR, Inventory, CRM, and AI). Supports multi-tenant isolation, automatic tenant resolver filters, and centralized database migration seeding.

Powered by OpenIddict with support for JWT bearer tokens and standard OAuth2 / OpenID Connect protocols. Features granular permission trees, role-based authorization (RBAC), and flexible multi-format logins (Email, Username, or Mobile Phone number).

Complete containerized orchestration via Docker and Docker Compose (SQL Server 2022, ASP.NET Core API Host, and Angular SPA with Nginx reverse proxy). Automated CI/CD pipeline deployments with the frontend hosted on Vercel and backend on high-performance ASP.NET hosting with live Swagger UI.
