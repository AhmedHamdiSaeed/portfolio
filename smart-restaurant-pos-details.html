Sahm Smart Restaurant POS & KDS

github.com/AhmedHamdiSaeed/SmartRestaurantPOS

A high-performance Angular 18 restaurant POS dashboard designed for intense dining room workflows — featuring real-time kitchen monitors, AI meal suggestions, and zero-downtime offline transaction queuing.

Implements a 4-column reactive Kanban order board (New, In Kitchen, Ready, Served) with drag-and-drop state transitions, dynamic priority indicators, and live order simulation backed by NgRx SignalStore.

Features an AI Assistant panel with character-level response streaming, recommending optimal food pairings, allergen alerts, and item modifiers with lazy-loading (@defer) and graceful failure recovery.

Built with an offline-first transaction queue using localStorage and exponential backoff retry policies. Includes a dedicated Kitchen Display System (KDS) featuring SVG load gauges, sparkline rush trends, and station bottleneck monitors.

Key Features

  • Angular 18 SignalStore Architecture
  • Real-time Kitchen Display (KDS)
  • Streaming AI Recommendations
  • Offline-First Transaction Queue
  • Table Floor Plan Management
  • Comprehensive Jest Test Suite
